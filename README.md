# Elite Marathon Analytics

精英马拉松赛事分析平台，浏览器端零运行时依赖，支持本地运行与静态站点部署。

## 运行

双击 `start-preview.cmd`，自动在后台启动本地服务并用默认浏览器打开 http://127.0.0.1:4173/。已启动时直接复用，不会重复启动服务。需要已安装 Node.js 22+；关闭网页后服务仍在后台运行，重启电脑后需再次双击脚本。启动错误可查看 `preview-server.log`。

首次构建先运行 `npm install`，然后执行 `npm run build:preview`。双击生成的 `preview.html` 即可打开不依赖服务器或 `node_modules` 的完整交互预览（推荐使用 Chrome / Edge）。浏览器对 file:// 的存储支持可能不同，重要数据请导出备份。

源代码开发预览需要 Node.js 22+：

```powershell
npm start
```

打开 http://127.0.0.1:4173。仅绑定本机回环地址。

```powershell
npm test
```

运行 `npm run check` 会先重新生成离线预览，再执行全部自动化测试。

## 架构

- `dist/index.html` / `style.css`：响应式深浅主题界面，无远程字体或资源。
- `dist/app.mjs`：事件、表单、SVG 交互图表、localStorage 保存、JSON/CSV 文件操作。
- `dist/core.mjs`：纯函数计算、统一数据校验、CSV 解析与生成、明确标注的虚构模拟数据。
- `server.mjs`：仅用于本地预览的静态服务器。`dist/` 可按 Sites 静态站点流程发布；已部署至 ChatGPT Sites，当前站点访问权限为仅所有者。
- `build-preview.mjs`：由 `esbuild` 解析 ES Module 依赖图并生成离线单文件 `preview.html`，避免正则剥离模块语法造成的作用域冲突和依赖顺序风险。`esbuild` 仅用于开发构建，不进入浏览器运行环境。
- `tests/core.test.mjs`：Node 原生自动化测试，无测试框架依赖。

数据结构为 `{version:1,races:[{id,name,date,demo,athletes:[{id,name,bib,country,color,target,splits:[{distance,seconds}]}]}]}`。target 和 seconds 为秒，distance 为公里。空目标使用 null。所有计算保留浮点精度，仅格式化显示时取整。

支持 5、10、15、20、21.0975、25、30、35、40、42.195 km。累计用时严格递增，允许漏录；漏录时使用相邻已有记录之间的真实距离计算，不插值。排名和时间差严格使用同一计时点。预计完赛基于累计均速，不声称具有模型预测能力。

JSON/CSV 导入全量校验后追加副本，保留模拟字段并生成新 ID。CSV 保留空赛事、空选手、目标、逗号和换行，并处理常见电子表格公式前缀。支持最多 100 场赛事、每场 200 名选手、5 MB 导入文件、48 小时累计用时。

## 存储与边界

数据只保存在当前浏览器、当前源的 localStorage。不同浏览器、预览面板与端口可能有不同工作空间；迁移请先导出 JSON。保存异常会显示提示。读取损坏的已有数据时不静默覆盖，提供下载原始备份的入口。不提供应用账号或云同步，也未连接实时计时设备。内置伦敦赛事包含官方完赛成绩及注明来源、待核验的第三方分段数据。

## 当前验证结果

36 项自动化测试通过，其中离线构建测试会实际运行 `esbuild`，并检查生成页面不再引用外部脚本或样式。桌面、手机、深浅主题、键盘操作、弹窗、数据恢复和大数据量场景均已在真实浏览器中完成验证；临时截图和一次性检查脚本不随项目长期保留。本轮未改变伦敦赛事的原始成绩。

带有“模拟数据”标识的赛事和成绩为虚构；伦敦赛事的官方完赛成绩与第三方中途分段分别注明来源，不能把所有数据都视为模拟，也不能把所有分段都视为官方逐点核验。

## 后续适合扩展

### 当前界面与伦敦赛事更新

- 创建赛事名称示例为 `2026 TCS London Marathon`；自定义日历的 `+` 前进一个月，`−` 后退一个月，支持跨年及键盘操作。
- 移除黄色提醒横条、左下本地工作空间卡片和页脚技术提示。模拟赛事仍使用名称旁的紧凑标签标识。
- 增加男子精英组、女子精英组、未分组。排行榜、领先优势、时间差、图表及选手详情按组别隔离。
- `data/london-2026-top4.json` / `.csv` 是男女各前四名已核实的完赛记录；姓名、国籍、名次和完赛时间来自 [World Athletics 官方结果](https://worldathletics.org/competition/calendar-results/results/7235562)。未填写目标、号码布或未经核实的中途计时。JSON 保留来源元数据。
- CSV 新增可选 `group` 列，继续兼容旧版 12 列文件。分组及 CSV 向后兼容均有自动化测试覆盖。

### 后续方向

分段补全：`data/london-2026-with-splits.json` / `.csv` 包含 8 人各 10 个累计计时点。中途记录主要来自 MyRace 第三方公开分段表，不能视为官方逐点核验；来源差异在数据管理中展开查看。`split-import.mjs` 在每个浏览器首次加载更新时，仅向现有伦敦赛事、现有选手补缺失计时点，保留手动值，先备份再保存并记录一次性标记。若手动值与新增点冲突，该选手跳过补全。不会恢复删除的赛事或选手，也不是持续跨浏览器同步。浏览器已验证 80 个计时点和刷新后持久化。

1. 官方计时源适配、断线补传、去重与审计历史。
2. 滚动配速预测、赛道高程与气象修正，并展示置信区间。
3. 赛事分组、个人最好成绩比较、负分段和战术分析。
4. 大屏观赛模式、可分享只读报告；按需要再引入后端与权限。

## 可用性改进

图表按容器宽度绘制、使用12px刻度；1100px以下主区域单列，520px以下选手详情单列。长录入窗口固定操作栏、分段摘要吸顶、字段错误提示并定位。完整重绘恢复焦点，滑块使用局部更新，支持键盘方向键选择。当前查看赛事、组别、图表和计时点存于当前标签页的 sessionStorage。默认最多显示12人，可切换全部或仅当前选手。分段表使用固定姓名列/表头和44px编辑按钮。修复空号码布、损坏数据恢复、目标进度与并列第一标识；移除装饰数据柱状图。

时间轴位于图表之前；矮桌面窗口压缩上方摘要，手机统计卡可横向滑动。顶级导航切换回顶部，组别/模式切换保持滚动位置。时间差刻度采用适合秒/分钟的间隔，窄图交错横轴标签，宽图增加绘图区高度。并列领先显示人数，终点第四张统计卡显示完赛人数。来源链接默认折叠并提供至少44px高的点击区域；第三方分段的同秒记录仅代表来源表格数值相同，不能据此确认集团计时或战术动作。存储发生异常时才显示可关闭的处理提示，正常浏览不显示提醒横条。
